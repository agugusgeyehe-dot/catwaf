The Analytics page shows two real views built from your actual request log: a 24-hour traffic volume chart, and a breakdown of attack types seen (SQL injection, XSS, path traversal, and so on).

Like the rest of the dashboard, this reflects genuinely inspected traffic. A quiet site with little attack traffic will show a mostly flat, low chart — that's an accurate picture, not a sign something's broken.

If you want the full detail behind any of these numbers — which requests, which rules fired — that's in the blocked-request log; see "Reading blocked requests and attack logs."
